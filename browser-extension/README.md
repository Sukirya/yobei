# Yobei 浏览器扩展

连接 Yobei 桌面端，在网页里填充账号密码。扩展本身是瘦客户端：**不存条目、不存主密码、不读保险库文件**，所有数据都存在桌面端，扩展只通过本机 loopback 接口（`http://127.0.0.1:19445`）访问。

设计见 `docs/adr/0011-desktop-tray-and-browser-extension.md`。无构建步骤：纯 JS + HTML + CSS，不用装任何依赖。

## 安装（Chrome / Edge）

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`），打开右上角"开发者模式"。
2. 点"加载已解压的扩展程序"，选择本目录（`browser-extension/`）。
3. 点工具栏里的 Yobei 图标打开 popup。

## 配对

1. 打开 Yobei 桌面端，进入扩展设置页，复制令牌。
2. 在扩展 popup 里点右上角"设置"，把令牌粘贴进去；端口一般不用改（默认 `19445`，桌面端端口被占时会自动顺延，实际端口以桌面端显示为准）。
3. 点"保存设置"。之后 popup 会显示保险库状态。

令牌只存在扩展的 `chrome.storage.local` 里。想作废随时在桌面端重新生成令牌，旧令牌立即失效。

## 使用

- **填充**：打开登录页，点扩展图标，点一条账号即填入页面；有 TOTP 的条目会多一个"复制验证码"按钮。
- **保存新登录**：在网页里正常登录一次，扩展会记住这次登录，popup 里出现"保存新登录？"，点"保存"就存进保险库（同网站同用户名已存在时只更新密码），点"丢弃"就扔掉。
- **生成密码**：popup 里点"生成密码"，生成 20 字符含符号的密码并自动复制到剪贴板。
- **锁定**：popup 里点"锁定"，或在桌面端托盘菜单里点"锁定"。锁定后扩展只能解锁，不能读条目。

桌面端点关闭按钮不会退出，只会隐藏到托盘继续运行，扩展才能一直用；只有托盘菜单里的"退出"才是真正退出，退出后扩展会报"桌面端未运行"。

## Firefox

扩展是 Manifest V3，理论上 Firefox 也支持，但**尚未验证**。Firefox 的 MV3 对 service worker 与部分 API 的支持和 Chrome 有差异，装之前请先在 Chrome / Edge 上确认流程。

## 安全说明

- 扩展只存 loopback 令牌（`chrome.storage.local`），不存任何条目、密码、主密码。
- 与桌面端的通信只走 `127.0.0.1`，不出本机；除 `GET /v1/ping` 外所有接口都要 Bearer 令牌。
- content script 只在有密码框的页面工作，不监听按键、不主动上报页面内容；凭证只在用户点"填充"或提交登录表单时才流动。
- 桌面端常驻托盘期间，已解锁的保险库密钥一直在桌面端内存里；不用时点"锁定"，并建议配合系统锁屏使用。
