# ADR-0006：平台解锁能力阶梯

- **状态**：已采纳
- **日期**：2026-11-01
- **决策者**：Sukirya
- **依赖**：ADR-0001（密钥层级）、ADR-0002（新设备加入）

## 背景 / 上下文

自动填充是一等入口，用户一天可能触发几十次。如果每次都要完整输入主密码和 Secret Key，
用户会关闭自动填充，产品价值随之消失。

但并非所有设备都支持生物识别，也不能假设用户为保险库单独设置了锁屏。
需要一套"设备能力不同、体验不同、安全性不退化"的阶梯，而不是二选一。

关键区分：

- **Secret Key** 参与密钥推导，决定"能不能解开库"。
- **生物识别 / PIN / 系统密码** 只是"允许不允许这台设备动用本地保存的钥匙"的手续，不参与推导。

## 决策

### 1. 支持范围

- Android 11 及以上（系统锁即可保护密钥，不强制要求生物识别）。
- Windows 10 及以上（Windows Hello / DPAPI）。
- Linux 推迟；macOS 随桌面端后续支持。

### 2. 解锁能力阶梯

| 设备能力 | 日常解锁 | 自动填充 |
|---|---|---|
| 强生物识别（指纹 / 3D 面容） | 生物识别 | 可用 |
| 弱生物识别（2D 人脸等，系统判定不足以单独保护密钥） | 系统要求输入锁屏 PIN / 密码 | 可用 |
| 有屏幕锁（PIN / 图案 / 密码） | 锁屏凭据 | 可用 |
| 完全没有屏幕锁 | 每次主密码 | 默认关闭，可手动开启并显示警告 |
| 桌面无 Windows Hello / 无 TPM | 系统账户密码或主密码 | 可用，但每次需确认 |

**"有没有生物识别"只影响手感，不影响可用性。** 设备凭据（PIN/系统密码）是等价的手续。

### 3. 设备密钥与 Vault Key

- Vault Key 用设备密钥包裹后保存在系统安全区（Android Keystore、Windows DPAPI / Hello）。
- 每次解锁需要一次系统认证；认证失败可回退到下一档，最终回退到主密码。
- 设备密钥随系统生物识别变更、恢复出厂设置、系统安全区失效而失效——此时回退到
  "主密码 + 恢复套件"，不视为数据丢失。

### 4. 填充解锁与管理解锁分离

| 场景 | 要求 |
|---|---|
| 自动填充一条凭据 | 一次系统认证即可；解锁后可维持短会话（建议 5 分钟），锁屏 / 熄屏立即失效 |
| 查看某一条目的完整秘密 | 同一次短会话内允许 |
| 查看全部条目、导出、修改主密码、管理设备 | 需要主密码；距上次主密码解锁超过 7 天时重新输入 |

这条把"日常顺手"和"高风险操作"分开：填充不强迫用户每天输密码，但批量导出、
改主密码这类操作必须证明是本人。

### 5. 新设备加入与救急恢复

- 只用"同步地址 + 主密码 + Secret Key"，不依赖旧设备（见 ADR-0002）。
- 恢复套件输入选择"粘贴 / 扫描二维码 / 手工分组输入"三种方式，都做同样的校验。

### 6. 无锁设备的处理

- 默认不允许开启自动填充。
- 用户手动开启时显示明确警告："这台设备没有屏幕锁，任何拿到它的人都能使用你的密码。"
- 无锁设备上，每次填充都要求主密码。

### 7. 撤销设备的语义

- 撤销只停止该设备与服务器的同步，**不能删除该设备本地的保险库**。
- UI 文案必须写成"该设备将无法再同步"，不得暗示远程擦除。
- 若用户怀疑设备被他人控制，正确的引导是：改主密码 + 撤销设备 + 在新设备上重建。

## 考虑过的其它选项

| 选项 | 否决原因 |
|---|---|
| A. 只支持生物识别 | 大量设备没有生物识别，会直接失去自动填充入口。 |
| B. 每次填充都输主密码 | 摩擦过大，用户会关闭功能。 |
| C. 解锁后永久保持 | 设备丢失即等于库丢失；不符合"设备会被物理接触"的威胁模型。 |
| D. 只要设备有锁就允许自动填充 | 无锁设备风险过高，需要默认关闭并警告。 |
| E. 撤销设备远程擦除本地数据 | 客户端不在线时无法保证执行；会给用户虚假的安全感。 |

## 取舍与后果

**得到：**

- 生物识别、PIN、系统密码都能成为日常解锁手段，覆盖绝大多数设备。
- 日常填充足够顺滑；高风险操作仍有主密码把关。
- 无锁设备有明确且诚实的降级路径。

**付出：**

- 需要维护设备能力探测与多档回退逻辑。
- 设备密钥失效（换指纹、重置系统）后必须走主密码恢复，用户会感知到一次"重新登录"。
- 7 天的主密码复确认会增加一次摩擦，但只作用于管理操作。

## 未决问题

- 短会话的准确时长（5 分钟是初始值，需要真机体验校准）。
- Windows Hello 不可用时的降级体验（DPAPI + 系统账户密码）。
